# 🏗️ Student Performance System Architecture

This project follows a professional **Service-Oriented Architecture (SOA)**, decoupling the user interface from the underlying data management and predictive intelligence layers.

---

## 🎨 Frontend: Streamlit Framework
The application is built using **Streamlit**, which provides a reactive web interface that communicates seamlessly with the Python backend.
- **Pages Module**: Encapsulate individual UI views (Dashboard, Prediction, Analytics).
- **Glassmorphism CSS**: Custom-styled components for a high-end visual experience.

## 🧠 Intelligence: AI & Machine Learning
The predictive engine is the core brain of the system.
- **Models Module**: Stores optimized binary model files (`.pkl`).
- **Predict Service**: High-performance inference engine that maps 5 student variables to a final predicted exam score.
- **Explainability**: Custom heuristics and driver analysis provide the "Why" behind every prediction.

## 🗄️ Persistence: SQLite Database
A unified **SQLite** relational database manages the ecosystem's consistency.
- **Users**: Secured authentication with `bcrypt` password hashing.
- **Students**: Academic profiles and role-based data.
- **Predictions**: Historical audit logs and time-series data for trend forecasting.

## 🛠️ Utilities & Helpers
A robust toolbox of helpers that maintain system integrity.
- **Validation**: Sanitizes all user inputs (including XSS protection).
- **Logger**: Centralized auditing of all system-critical operations.
- **File Handler**: High-speed bulk data ingestion and CSV/Excel exporting.
