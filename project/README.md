# 🎓 Student Performance Prediction System

## 🚀 Overview
This project predicts student performance using Machine Learning and provides interactive dashboards for students, staff, and admin.

---

## ✨ Features

- 🔐 Login / Signup System
- 🧠 ML-based Performance Prediction
- 📊 Interactive Dashboard (Plotly)
- 👨‍💼 Admin Panel
- 📧 Email Notifications
- 📁 Excel → SQLite Database
- 🎨 Animated UI (Lottie + CSS)

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- SQLite
- Plotly
- Lottie Animations
