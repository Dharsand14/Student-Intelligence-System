# 🔄 Project Flow & User Experience

The Student Performance System ensures a seamless, role-aware user journey through all academic tracking and AI-powered intelligence phases.

---

## 👨‍🎓 Student Journey
1.  **Authentication**: Secure login and registration with automatic role assignment.
2.  **Dashboard Hub**: Immediate visualization of their performance history and score trend analysis.
3.  **Active Prediction**: Use the **Prediction Page** to input current study habits and receive an AI-generated exam score forecast.
4.  **AI Explainability**: Receive detailed feedback (e.g., "Good sleep habits are positively contributing to your score").
5.  **Personalized Recommendations**: Get actionable advice based on current metrics.
6.  **Reporting**: Export personal history in CSV or Excel format.
7.  **Engagement**: Provide feedback via the **Feedback Center**.

## 🏫 Staff/Administrator Journey
1.  **Oversight Dashboard**: High-level university overview of all student averages and active participants.
2.  **Risk Management**: Review the **Critical Risks** alert board for students performing below the 40% threshold.
3.  **Advanced Analytics**: Access statistical heatmaps and feature correlation charts to find underlying class-wide patterns.
4.  **Bulk Ingestion**: Use the **Bulk Upload** tool to ingest entire cohort datasets (CSVs/Excel) with automated data cleaning.
5.  **Predictive Triage**: Perform one-off predictions on behalf of any student in the system for immediate evaluation.
6.  **Administrative Reports**: Filter the global registry and generate CSV/Excel exports for university board meetings.
