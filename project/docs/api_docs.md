# 🧬 Service Layer API & Technical Reference

The application uses an internal procedural service layer that encapsulates all business logic and AI-driven intelligence.

---

## 🧠 Intelligence Services: `services/`
### `predict.py`
High-performance inference function.
- `predict(data_dict)`: Executes the primary AI model prediction.
  - Takes features: `[Study Hours, Attendance, Mental Health, Sleep Hours, Exam Scores]`.
  - Returns: A rich response dictionary containing `score`, `was_weekly`, and `ui_metadata` (grade/icon).
  - Logs: Every inference is recorded via `log_event("PREDICTION_MADE", ...)`.

### `explainability.py`
The "Why" behind the AI model.
- `explain_prediction(...)`: Generates human-readable feedback on the major score drivers. Positives (`+`) vs. Concerns (`-`).

### `forecast.py`
Time-series prediction logic.
- `forecast_next_score(df)`: Calculates growth rate, trend, and projected next score based on current student history.
- `calculate_trend(...)`: Returns a string label for the score trajectory (↑ Improving, ↓ Declining, etc.).

---

## 🛠️ Utility Functions: `utils/`
### `validation.py`
System-wide input protection.
- `sanitize_text(text)`: Performs HTML-escaping and script-stripping for XSS protection in feedback and user data.
- `validate_student_id(sid)`: Regex-based pattern matching (e.g., STUXXXXXXX).

### `file_handler.py`
Data ingestion and export engine.
- `validate_prediction_df(df)`: Performs automated data cleaning, NaN-filling, and ID deduplication during bulk uploads.
- `convert_df_to_csv(df)` / `convert_df_to_excel(df)`: Standardized data formatters for administrative reports.

### `logger.py`
Centralized auditing.
- `log_event(event_type, username, details)`: Records a JSON-structured audit event into `logs/app.log`.
